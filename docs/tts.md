# Озвучка подсказок

После кнопки Stockfish Piper озвучивает тот же рекомендованный ход по-русски.
Звук идёт через **аудиовыход сервера Firefly**, не устройства с браузером.
Ход не выполняется. Флажок «Озвучивать на Firefly / сервере» отключает речь.
Смена позиции, настроек или новый запрос отменяют устаревшую озвучку.

YOLO работает на NPU; Piper ONNX и Stockfish — на CPU. Конвертация TTS/Stockfish
в RKNN не требуется. Piper получает один CPU-поток по умолчанию, загружается
при первой озвучке и хранит до 64 WAV в памяти. Первый синтез медленнее.
Очередь содержит максимум одну ожидающую подсказку; синтез не блокирует API.

## Подготовка

Загрузите голос Ирины из публичного репозитория Piper:

```bash
python3 tools/import_tts.py
uv sync --project web --extra tts
```

Скрипт загружает ONNX и конфигурацию в `artifacts/tts` из закреплённой ревизии
`rhasspy/piper-voices` на Hugging Face и проверяет SHA256. Нужен интернет только
для первой загрузки; существующие корректные файлы используются повторно.
Синтез речи работает офлайн. Другой каталог можно задать через `--output`;
для запуска с ним укажите `EDGECHESS_TTS_MODEL`.

При локальном запуске также укажите extra, например:

```bash
uv run --project web --extra tts --locked uvicorn web.backend.app:app --host 127.0.0.1 --port 8000
```

Путь `STOCKFISH_PATH` и настройки YOLO задаются как в [локальном запуске](local.md).

На Firefly зависимости устанавливайте **только внутри активного conda**.
Для ALSA-проигрывателя: `conda install -c conda-forge alsa-utils`.
При упаковке добавьте `--with-tts` к команде `tools/package_firefly.py`:
модель, конфигурация и зависимости Piper войдут в архив; установка — прежним
`tools/install_firefly.sh` внутри conda. Без этого флага TTS остаётся опциональным.

## Аудиовыход

```bash
aplay -l
aplay -L
export EDGECHESS_AUDIO_DEVICE=default
```

Если default направляет звук в HDMI, выберите аналоговый выход по результатам
`aplay -L`, например `plughw:CARD=имя_карты,DEV=0`. Номера карт не фиксируем:
они зависят от ОС и подключённого оборудования. Проверьте громкость и mute.
Обычные наушники или активные колонки подключаются к выходу 3,5 мм, если он
есть на вашей модели платы. Начинайте с небольшой громкости.

Настройки: `EDGECHESS_TTS_MODEL` — путь к ONNX (рядом нужен `.onnx.json`),
`EDGECHESS_TTS_THREADS` — 1–4 (по умолчанию 1), `EDGECHESS_AUDIO_DEVICE` — ALSA PCM.
Статус и ошибки отображаются в карточке Stockfish; подробности — в журнале
сервера. Отсутствие Piper, модели, aplay или ошибка устройства не мешают
текстовым подсказкам. Успешный выход aplay не доказывает физическую слышимость.

## Источник и лицензии

Используется Piper 1.3.0 (GPL-3.0-or-later), совместимый с генератором AudioChunk.
Голос: `ru_RU-irina-medium`, 22050 Hz, около 63 МБ.
[Карточка голоса](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/irina/medium/MODEL_CARD)
указывает лицензию датасета как Unknown. Голос не коммитится; перед публичным
распространением архива с ним необходимо уточнить права на модель/данные.

Проверка локального синтеза не заменяет проверку ARM64, аудио и FPS на плате.
