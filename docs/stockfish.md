# Stockfish

## Подсказка

1. Задайте начальную позицию или загрузите допустимый FEN.
2. Выберите сторону помощника.
3. Дождитесь подтверждения распознавания и нажмите «Подсказать ход».

Исходная клетка подсвечивается синим, целевая — зелёным. Подсветка и текст
не выполняют ход. Подсказки не попадают в изображения, отправляемые YOLO.
При изменении позиции или настроек помощника предыдущая рекомендация сбрасывается.

По умолчанию требуются два последовательных совпадения YOLO с текущей
расстановкой: `status=ok`, без предупреждений, последний кадр не старше трёх
секунд. При чужом ходе, завершённой партии или неподтверждённой позиции
кнопка недоступна.

Отключение «Подтверждать позицию через YOLO» включает режим `history_only`.
Он использует только историю виртуальной доски. Загруженный JPEG
не подтверждает позицию виртуальной партии.

## История и API

История передаётся серверу как начальный FEN и список ходов UCI. Сервер
проверяет легальность, очередь хода, рокировки, en passant, счётчики и
повторения. История не передаётся нейросети и не исправляет её детекции.
Загрузка FEN начинает новую историю; предшествующие повторения не восстанавливаются.
До 32 сессий хранятся в памяти; перезапуск сервера удаляет их.

| Запрос | Данные |
|---|---|
| `POST /api/game` | `game_id`, `revision`, `initial_fen`, `moves`, `side` |
| `POST /api/advice` | `game_id`, `revision`, `require_vision` (по умолчанию `true`) |

HTTP 409 — позиция не готова, устарела или движок занят; HTTP 503 — ошибка
движка. Допускается один расчёт одновременно. Устаревшие ответы отбрасываются.
«Повторить синхронизацию» повторно передаёт историю из браузера.

## Настройки

| Переменная | По умолчанию | Допустимые значения |
|---|---|---|
| `STOCKFISH_PATH` | поиск `stockfish` в PATH | путь к исполняемому файлу |
| `EDGECHESS_STOCKFISH_SECONDS` | `1` | `0.05`–`10` секунд |
| `EDGECHESS_STOCKFISH_THREADS` | `1` | `1`–`4` |
| `EDGECHESS_STOCKFISH_HASH_MB` | `64` | `1`–`256` MiB |

Настройки применяются после перезапуска. Stockfish работает в отдельном
CPU-процессе, независимо от inference-worker. Загрузчик закрепляет версию 19
и проверяет SHA256. При распространении сохраняйте исходники и GPL-уведомления.

Запуск: [локально](local.md), [на Firefly](firefly.md).
