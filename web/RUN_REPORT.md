# Проверка первой версии веб-интерфейса

Проверено 21 сентября 2026 года. Сервер: Linux x86_64, Python 3.10.20,
ONNX Runtime 1.20.1, CPUExecutionProvider, четыре потока, batch=1.
Браузер на отдельном компьютере обращался к серверу через SSH-туннель.
Адреса и особенности локальной среды в конфигурацию приложения не включены.

Модель: `yolov8s.onnx`, SHA256
`ab576a3384251b8a6aff16556712fd53f26bb7753f629202d3f400be46d49c82`.

## Автоматические проверки

- `uv sync --locked`: среда устанавливается из `uv.lock`.
- `uv run --locked pytest -q`: **6 passed**, включая настоящий ONNX.
  Проверены latest-frame очередь, перекрытие приёма и инференса,
  отключение/повторный вход, отказ второму клиенту, неверный формат сообщения,
  повторный id кадра и преобразование координат после letterbox.
- `npm run build`: TypeScript и production-сборка Vite 6.4.3 проходят.
- `npm test`: **3 passed** — процентили, координаты рамок, шахматные операции.
- `npm audit`: 0 найденных уязвимостей на момент проверки.
- `convert/06_check_postprocessing.py`: letterbox совпадает с Ultralytics на
  трёх соотношениях сторон и тестовых изображениях; NMS/координаты также совпадают.

Сборщик сообщает о JS-бандле около 584 КБ (154 КБ gzip), включающем Three.js.
Это предупреждение о размере, сборка успешна. В Python-тестах есть предупреждение
об устаревшем алиасе AnyIO внутри Starlette TestClient; тесты проходят.

## Проверка в браузере

- Сцена отрисовывается, настоящий ONNX возвращает detections и измерения.
- Некорректный FEN показывает ошибку; корректный FEN меняет позицию.
- На разреженной тестовой позиции ход e2–e4 выполнен кликами: FEN обновился,
  очередь перешла к чёрным. Начальная позиция восстанавливается кнопкой.
- Вращение и масштаб камеры работают; bbox не перехватывают мышь и остаются
  видимыми при движении. Запаздывание рамок наблюдается, как предусмотрено.
- Снятие чекбокса убирает рамки, при этом счётчики и инференс продолжаются.
- JSON скачан и прочитан: 404 измерения, модель, настройки, счётчики.
  CSV скачан и разобран: 150 строк измерений с корректными заголовками.
- Выход со страницы и повторное открытие восстанавливают поток.
- Проверена компоновка при ширине 390 px: горизонтального переполнения нет.
- Ошибок JavaScript в проверенном сеансе не было.

## Измерения

В нескольких пятисекундных окнах активной сцены: примерно 8.4–8.8 обработанных
кадров/с, около 29 захватов/с при лимите 30; p50 инференса примерно 108–114 мс,
p50 возраста результата примерно 145–156 мс. Это наблюдения данного запуска,
а не гарантии и не результаты NPU. При замедлении браузера фактический FPS
падает независимо от скорости ONNX; интерфейс показывает частоту захвата отдельно.

Изолированный бенчмарк без активного потока: пять прогревочных проходов,
30 измерений на одном заранее подготовленном изображении:

| Показатель | Значение |
|---|---:|
| Средняя задержка `session.run()` | 108.53 мс |
| p50 | 108.54 мс |
| p95 | 109.60 мс |
| Расчётная скорость модели | 9.21 кадров/с |

Предсказания временной модели на процедурных фигурах содержат пропуски и неверные
классы. Они отображаются без исправления по FEN. Геометрия сцены не является
копией ChessRender360; точность финальной модели нужно будет оценить отдельно.
