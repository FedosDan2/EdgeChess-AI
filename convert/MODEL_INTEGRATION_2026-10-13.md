# Две модели в общем 3D-пайплайне

В 3D доступны новая YOLOv8m (`chess3d_m`, default) и предыдущая дообученная
YOLO11s (`chess3d`). Веса и конвертированные артефакты хранятся раздельно;
preprocessing, декодирование, NMS, геометрия и FEN общие. 2D сохраняет каскад
board2d → pieces2d. HTTP/WebSocket принимают необязательный `model`, UI
предлагает установленные модели и скрывает выбор в 2D. Старые profile/backend
параметры поддерживаются; выбор по умолчанию можно задать EDGECHESS_3D_MODEL.
При смене модели прежняя сессия закрывается до загрузки следующей.

Новые веса: `cv@7e497a8`, `CV_3D/weights/best_new_scratch.pt`.
SHA256: `5dfce3c339e85015326301f9dc0514507e44ab2d4e5546d2f9943402926a054b`.
Прежние fine-tuned веса: `cv@87545eb`, активный файл
`CV_3D/weights/best_3d_detection.pt`. Их артефакты не перезаписывались.

## Проверки новой конвертации

Использованы 128 train-изображений synthetic-2000 для калибровки и 32 test
для численной проверки; source manifest содержит ссылки и хеши исходных PNG,
без копирования исходного датасета. Данные и артефакты модели разделены через
MODEL_DATA в vision/config.py. Новые артефакты: convert/artifacts/chess3d_m.

ONNX и split ONNX прошли сравнение с PyTorch на всех 32 кадрах. Итоговые
детекции совпадают при IoU ≥ 0.99. Максимальная обнаруженная разница сырых
вероятностей — 0.000061, в выбранных детекциях того кадра — менее 0.000001.
Абсолютный FP32-допуск сырых вероятностей уточнён до 0.0001 для большей сети;
проверка итоговых детекций и допуск координат не изменены. LetterBox, NMS
и восстановление координат проверены отдельно относительно Ultralytics.

| RKNN | Recall совпадения | Precision совпадения | Порог ≥95% |
|---|---:|---:|---|
| FP16 | 100% | 100% | пройден |
| INT8, normal | 97.88% | 98.38% | пройден |

Это проверка конвертации в симуляторе Toolkit2 при IoU ≥0.9 и confidence ≥0.25,
а не метрики качества обучения или измерения NPU. Качество обучения повторно
не оценивалось по просьбе пользователя. Хеши ONNX/RKNN сверены с отчётами.
У прежней YOLO11s ранее собранный INT8 всё ещё имеет passed=false; UI сохраняет
предупреждение, без скрытой замены backend или модели.

## Runtime и упаковка

Backend: 12 тестов прошли, включая освобождение сессий, повторный выбор без
перезагрузки, отклонение неизвестной модели, реальный 2D/3D инференс и передачу
параметра через HTTP и WebSocket. Frontend build и unit-тесты прошли.
Браузерный тест подтвердил реальный поток для маршрута
YOLOv8m → YOLO11s → 2D → YOLO11s → YOLOv8m, без ошибок JavaScript.
Отдельно прошла регрессия вращения, точного сброса камеры и ходов в 2D/3D.
Перед исходным снимком тест управления ждёт завершения resize/render.

Локально собран и проверен artifacts/firefly-two-3d-models.tar, 131.62 MiB:
2D-каскад, обе 3D-модели, FP16/INT8, frontend и runtime. Внутри нет PT, ONNX,
датасетов, venv или .env. Упаковщик поддерживает --3d-models для выбора только
нужных моделей. Архив на плату не отправлялся.

Проверка SSH Firefly выполнена только для чтения ресурсов: диск заполнен на
98%, свободно 473 MiB. По ограничению пользователя установка и NPU-тесты
не выполнялись; ничего не скопировано/удалено, чужие процессы не остановлены.
Нельзя утверждать о проверенной совместимости и скорости новой модели на NPU.

Логи конвертации: artifacts/model-integration-20261013. Инструкции выбора
моделей: web/README.md; команды экспорта: convert/README.md.
