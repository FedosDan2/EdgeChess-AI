# Обучение 3D-моделей

Для распознавания используйте общий runtime `vision` и
[web-ui](web/README.md). Старый `CV_3D/main.py` и дублирующий пайплайн
не включены в объединённую версию.

## Данные и обучение

- `setup_dataset_3d.py` — исходная подготовка ChessRender360 из ветки `cv`.
  Скачивает около 26 GB; нужны `kagglehub`, `albumentations`, `opencv-python`,
  `numpy`, `pyyaml`, `tqdm` и доступ к Kaggle.
- [Генератор синтетических данных](web/frontend/DATASET.md) использует текущую
  сцену UI; сервер инференса и Firefly для него не нужны.
- `CV_3D/fine_tune.py` — дообучение существующей модели.
- `CV_3D/train_3d.py` — обучение от COCO-предобученной YOLOv8m.
- `CV_3D/check_res.ipynb` — исходный исследовательский ноутбук сравнения весов.

Обучающие скрипты требуют отдельного окружения Ultralytics/PyTorch с GPU;
это не окружение минимального NPU-runtime. Исходные версии зависимостей
не зафиксированы. До запуска настройте пути к данным, весам и GPU в скриптах;
ноутбук содержит локальные пути автора. В частности, генератор сцены по
умолчанию пишет в корневой `data/`, а обучение ожидает данные в `CV_3D/`.

**Ограничение исходной подготовки ChessRender360:** случайные аугментации
применяются также к `original`, `val` и `test`. Перед новым обучением и
независимой оценкой этот скрипт необходимо исправить. Проверьте также
`OUTPUT_PATH`: исходное значение содержит дополнительный каталог `EdgeChess-AI`.

## Веса

| Файл в `CV_3D/weights/` | Назначение |
|---|---|
| `best_new_scratch.pt` | YOLOv8m, текущая модель `chess3d_m` по умолчанию |
| `best_3d_detection.pt` | Дообученная YOLO11s, текущая модель `chess3d` |
| `best_fine_tuned.pt` | Исходное имя тех же дообученных весов из `cv` |
| `best_original.pt` | Исходная модель `best_3d_detection.pt` из `cv`, до замены дообученными весами |
| `best_scratch.pt` | Дополнительный экспериментальный checkpoint из `cv`, runtime его не выбирает |

Исходная и дообученная модели сохранены раздельно: один и тот же путь
`best_3d_detection.pt` в объединяемых ветках содержал разные веса. Активное
имя сохранено совместимым с метаданными уже экспортированной YOLO11s.

Веса `.pt` загружайте только из доверенного источника. Подготовка ONNX/RKNN
и численные проверки: [convert/README.md](convert/README.md).
